# IVOAI v0.11.0

This release adds the governed Claude Red catalog and refreshes the managed
components and dependency locks reviewed on 2026-10-11. It also removes the known
Go and npm audit findings without advisory exceptions.

## Security and compatibility

- Go 1.27.2 and current compatible Go modules replace the vulnerable toolchain.
- Documentation and Ruflo dependency locks include patched upstream dependencies.
  `braces` has no upstream fix for GHSA-vfj7-8cjw-p6xm on the review date: IVOAI
  supplies the MIT-preserving local `3.0.4-ivoai.1` patch, bounding parser nesting,
  AST traversal and parent chains, and rejecting non-string AST values. Tests
  cover deep/cyclic inputs and ordinary expansion. See `patches/braces`.
- Ruflo stages the reviewed local archive under its isolated install prefix,
  verifies its SHA-512, and runs npm from that directory with scripts disabled.
  Its optional SLIM binding is pinned to stable 2.2.0 within the declared major;
  the upstream alpha references unpublished platform artifacts. SLIM 3.x is not
  forced across a major API boundary. Provider execution remains disabled.
- The immutable embedded skill catalog is decoded once and returned as independent
  copies. Installed overlays still undergo validation on each use; concurrent
  caller mutations cannot alter release policy. This reduces repeated setup work.
- No global agent installation, account credentials, sandbox, or authorization
  policy is replaced. No production deployment is performed by this release.

## Upgrade and rollback

Use the existing TUI and `ivoai update`, `ivoai skills update`, `pin` and `rollback`
commands. Skills only activate reviewed immutable revisions. Existing profiles,
personal skills and external executables retain their ownership boundaries.

Before upgrading an ai-memory 1.x server, back up its persistent data and server
configuration while writes are stopped. The 2.x server may migrate its database.
Rolling back an executable or image does not undo a database migration: restore
the matching pre-upgrade data snapshot as well. This release changes the reviewed
server template; apply it only through a controlled server update. Do not deploy
or restore over a running production database.

GitHub Actions verifies the release before publishing immutable Linux amd64 and
arm64 archives, patched OpenCode archives, metadata, the Web skill ZIP and a
checksum file. Checksums establish integrity against the reviewed source; they
are not represented as independent signatures.
