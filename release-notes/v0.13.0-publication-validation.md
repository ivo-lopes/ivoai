# v0.13.0 publication validation

[v0.13.0](https://github.com/ivo-lopes/ivoai/releases/tag/v0.13.0) was published
from `49445919f745157e3c8aa1c717161e49cb5f50d5`, after PR31/32/33 passed their
15 exact-head CI jobs each. The merged source also passed its full
[main CI40604223389](https://github.com/ivo-lopes/ivoai/actions/runs/40604223389).
The separate [release run40604246722](https://github.com/ivo-lopes/ivoai/actions/runs/40604246722)
passed all five jobs: verify, skill, AMD64 build, ARM64 build and draft-first
asset publication. No production deployment or personal installation was run.

Post-publication, all **12 public assets** were downloaded and their byte counts
and SHA-256 values compared with the GitHub asset digests. `checksums.txt` had
exactly the other 11 expected names with matching hashes. Both architectures'
managed Graft/OpenCode JSON metadata identified the corresponding archive,
platform and digest. The [sanitized verification report](evidence/backend-first/release-v0130/published-asset-verification.json)
retains all identities and verdicts, without payloads or credentials.

Both Core archives contained exactly one regular ELF executable named `ivoai`.
Go build metadata identified Go1.27.3, the expected architecture, source commit
49445919 and `vcs.modified=false`. The AMD64 binary also reported GOAMD64=v1 and
executed `version` (0.13.0) and `help` successfully with temporary HOME/XDG roots.
The ARM64 executable was inspected locally, **not executed on this AMD64 host**.
Runtime and baseline-CPU checks belong to the architecture-specific release CI;
the local GOAMD64=v1 metadata alone is not execution on a CPU without AVX.

This release delivers the benchmark/gateway/intake/Core-contract foundation and
dependency remediation described in the bilingual release notes. The global
16-scenario economic gate remains **INCOMPLETE**; the retained final prior
three-case subset remains **FAIL** against 10% input / 5% elapsed targets. No
new inference or rescoring was used to validate publication. OpenCode removal,
general adaptive no-DAG execution, broader gateway recovery and native-client
parity remain pending. Context synchronization remains BLOCKED under IVOAI-175.

The later VERSION pilot (PR34), RTK output-view pilot (PR35) and reported-usage
trace addition (PR36) are outside this immutable tag. They must not be credited
as features of v0.13.0. Further merges on main do not change the tagged bytes.
