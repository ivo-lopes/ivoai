## Read and provenance

`Router.ReadMemoryPageExact` accepts only bounded `query` **or** normalized relative `path` arguments for `memory_read_page`. Unknown/duplicate JSON fields and unsafe/ambiguous arguments are rejected. The caller must supply a Core authorization callback and a host context key; a context hash alone grants nothing. `MemorySnapshotScopeKey` binds that domain to the original session and existing Evidence Scope. These are host API inputs, never upstream RPC arguments or model-authored policy.

The read reuses the existing Router HTTP client, credentials, selection, timeout, circuit and source provenance. It requires one selected profile, without federation/failover. The method supports the pinned SDK's stateless POST behavior; it neither creates a second authentication client nor negotiates remote sessions or resumption. Redirects are refused for this host operation without changing legacy redirect behavior. Every admitted successful LIVE read sends a new upstream request and produces a new host nonce, including identical arguments; denied/open-circuit attempts return an error rather than cached data.

A private per-call validator runs before `recordSuccess`. It checks the exact host-generated JSON-RPC ID, one exclusive result, unique JSON keys, finite JSON/SSE framing, supported text CallToolResult shape, no error/partial/truncated flags, HTTP 200 and no session/partial-response headers. It parses the entire SSE response, never the first usable event. Bounds are 1 MiB UTF-8 response, eight concurrent LIVE reads, JSON depth 32 / 8192 value nodes, 64 SSE frame slots, and 512-byte query/path inputs. Unsupported shapes fail closed.

Snapshots contain immutable private response bytes, a nonce, SHA256, exact result/argument digests, capture time, the real profile ID/alias/purpose/redundancy group and configured endpoint digest. They carry no credential/header or raw query in metadata. Byte getters return copies; zero/JSON-decoded lookalikes cannot mint snapshots. Capture time and nonce identify a received response, not the current version/freshness of a remote page or index. Error strings and existing observation events omit arguments, bodies and credentials.

## Retention and exact recovery

`Gateway.IssueMemoryPageSnapshot` requires independent **host** grant and retention callbacks. Neither is deserialized from model/upstream data. Retention defaults to unknown: no callback, unknown/nonpersistable sensitivity, invalid policy digest or unsupported TTL creates no artifact/cache/binding. Policy receives the whole opaque response so it can classify all content, including SSE framing; source annotations cannot select Internal/Restricted. Callers must construct policy after Core admission, not deserialize it from a prompt. This slice supplies no generic institutional retention policy. The positive test policy approves independently declared fixture result bytes; a separate SSE fixture approves its entire declared response.

The existing known-secret/redaction admission checks remain an additional defense. They do not certify arbitrary remote text safe to persist, and the implementation never redacts authoritative bytes to manufacture a successful snapshot. Host policy must explicitly approve sensitivity, policy digest and per-artifact TTL. `Request.ArtifactTTL` simply forwards that existing ArtifactStore capability; zero preserves legacy callers. Invalid nonzero TTL is rejected before fetch; Memory issuance requires 1 minute through the existing 7-day maximum. Policy/grant checks repeat before/after I/O and during recovery; changes deny access.

Only already captured bytes enter the existing Gateway cache. Its generation identifies an immutable nonce/SHA/source, never a constant generation for a live service. Explicit reuse can issue separate recipient-owned `evidence_` refs without another LIVE read. Original session/scope mismatch is denied even if a supplied callback would otherwise allow it. G0 protected-ID, canonical binding, exact SHA/ownership, capacity, quota, GC and restart-denial rules remain in force; no storage schema/kind or database is added.

Raw JSON is stored as JSON; original SSE is stored as plain UTF-8 bytes with its transport type retained in the snapshot descriptor. CRLF/comments/event framing are not normalized in stored evidence. Complete framing does not prove a complete page/corpus: `SourceComplete` remains false, with the existing coverage gap/ArtifactRef truncation metadata, while the artifact still contains the exact complete captured response. No page-completeness or correctness claim follows from parsing alone.

Retained authorized data may remain readable under current local policy while the remote service refuses new reads. Recovery does not contact the service and does not promise continuous remote revocation. A new LIVE request still goes upstream. Loss of the process-local binding fails closed; no reference is reconstructed from disk or client-supplied metadata. Old `artifact_` and old-Core protected-disk rollback limitations remain those documented by G0.
