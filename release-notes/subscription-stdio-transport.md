# Owned subscription stdio transport: test-only, official qualification pending

This increment implements the private Session seam prepared in `b495e7499514acbb43aaa770735a5f5b335e482b`. It remains in Linux `_test.go` files and has no production or real-cohort caller. The existing route projector and its scope/policy predicates are unchanged. No official client, RPC, status, authentication, model or personal configuration operation was executed.

The transport follows the existing quota/benchmark pattern of explicit pipes, owned process groups, pinned executables and Start/Wait. It does not reuse Facade's provider-rewriting path, create an auth store, invoke the diagnostic NativeRunner, add an orchestrator or introduce dependencies. The source seam remains the standalone shared-user-config benchmark profile; this branch is based on b495, not a claim of composition with a newer main or PR56 source.

The closure captures the reviewed directory/environment/arguments and rejects changed scope before starting a child. The official constructor fixes the approved main/companion digests, verifies both files before Start and verifies the actual running ELF through its owned `/proc/PID/exe`. The parent command is not mutated. Unit tests supply only hashes of a controlled fake Go executable and companion copy; this is not a way for model input to select an arbitrary official provider or bypass a production guard.

Only initialize, initialized, config/read, configRequirements/read and account/read are permitted, in exact order with fixed IDs and params. Any failure is terminal. Duplicate/wrong IDs, remote errors, server requests, partial frames, excessive nesting/nodes, oversized output and notification floods fail closed. The total stream is bounded before bufio to2MiB plus one overflow byte; notifications have separate16/64KiB budgets. Parsing reuses the existing duplicate/depth/node checks. Stderr goes to Discard; raw frames/config/account fields remain in bounded host RAM and never enter errors, logs, hashes, results or model context.

The session binds to the existing15s probe context and caller cancellation; it is not a new general-purpose RPC client. Closing IPC unblocks held reads/writes. Cleanup allows100ms for EOF, then300ms for TERM and a1s reap bound. It keeps the direct child unreaped until the last process-group signal, uses pidfd observation when supported and an own-child `/proc` snapshot fallback otherwise. It then calls Wait once. It does not search or signal unrelated processes.

A cleanup signal is not evidence that it caused a previously observed exit. The final code records whether the leader had already exited before TERM and KILL. A spontaneous nonzero exit, including a pre-observed SIGKILL, is refused. A matching signal can be accepted as intentional cleanup only when the leader was observed live before that host signal. This observation is not a kernel-level attribution of every possible concurrent signal sender. The prepared official qualification separately requires actual Wait0, so intentional TERM/KILL cleanup cannot satisfy its success gate.
