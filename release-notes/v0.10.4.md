# v0.10.4 — Linux amd64 installation compatibility

- Fix client setup on x86-64 hosts without AVX2, including Xeon E5 v2 servers. The managed OpenCode archive now uses the baseline CPU target instead of the AVX2 target that terminated with an illegal instruction during post-promotion health validation.
- Publish managed OpenCode `1.18.25-ivoai.2` with an archive-bound immutable object identity. Existing failed or working artifacts remain intact; setup installs the compatible artifact into its own verified object.
- Report the terminating signal in subprocess errors instead of the uninformative `exited with status -1`.
- Gate amd64 frontend builds on a checksum-verified executable smoke under a non-AVX CPU model, alongside the existing native TUI tests. ARM64 retains its native target.

Re-run the official installer and `ivoai setup` to recover a failed v0.10.3
installation. No manual deletion of the supply-chain directory is required.
This is an installation hotfix; the planned OpenCode Full Console feature is
not included in this release.

## pt-BR

- Corrige a instalação em hosts amd64 sem AVX2, incluindo Xeon E5 v2. O OpenCode gerenciado passa a usar o build baseline, eliminando o SIGILL durante a validação de saúde.
- Publica OpenCode `1.18.25-ivoai.2` com identidade imutável vinculada ao checksum do arquivo. Preserva os artefatos anteriores e instala a correção em um novo objeto verificado.
- Mostra o sinal que encerrou um subprocesso, em vez de apenas `status -1`.
- Adiciona teste do executável em CPU sem AVX/AVX2 à CI e à release, além dos testes existentes da TUI. ARM64 mantém seu target nativo.

Para recuperar uma instalação v0.10.3 interrompida, execute novamente o
instalador oficial e `ivoai setup`. Não apague o diretório supply-chain.
Esta release contém o hotfix de instalação; OpenCode Full Console permanece
para uma release futura.
