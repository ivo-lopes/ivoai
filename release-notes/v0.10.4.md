# v0.10.4 — OpenCode Full Console

- Add a scrollable, live operational console to managed OpenCode: one core-owned
  snapshot and bounded typed event ring for DAGs, workers, worktrees, exact MCP
  tool metadata, Skills/Ponytail, knowledge, quota and owned hook health.
- Add confirmed console actions for automation profiles and owned hook wiring,
  a runtime model catalog, and current-project Session Control. Native model,
  reasoning and approval interfaces remain in use; no second scheduler exists.
- Add economic/balanced/quality/custom presets to the existing orchestration
  policy and IVOAI TUI. Explicit provider/model choices and security gates remain
  authoritative. Changes apply to the next session, not running workers.
- Repair stale IVOAI/ai-memory hooks with ownership-scoped, idempotent preflight;
  preserve personal hooks and exclude ambient credentials from persistent wiring.
- Retain bounded, sanitized App Server startup causes through native TUI exit.
  Current fresh/existing startup is validated independently of the unavailable
  historical pre-update failure cause; that historical cause remains unknown.
- Share eligible Codex conversation state through isolated views, with official
  native discovery and explicit adoption. Same-provider transitions retain the
  native thread; frontend switches retain logical IVOAI identity. Provider
  changes use explicit bounded handoff, never transcript migration.
- Certify the current isolated-client team operating model and document its
  limits. IVOAI-174 remains Backlog: no distributed human locks or shared auth.

Legacy independent paginated Codex stores remain resumable in their original
mode. Rehoming them to another SQLite store is not supported by the inspected
official resume interface without copying data; IVOAI does not copy the database
or silently create a replacement thread. Console resume requires an existing
eligible frontend mapping; other transitions use the main IVOAI Session Control.

Next planned release: v0.10.5 — OpenViking Context Integration (not started here).

  quota e saúde de hooks, sem conteúdo bruto ou credentials.

  limitações distribuídas documentadas na IVOAI-174, ainda Backlog.
