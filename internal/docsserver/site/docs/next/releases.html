v0.14.0​

Published v0.14.0 on 2026-10-28 at 19:10:11 UTC from 6d99e320. All 12 public assets were downloaded and matched GitHub sizes/digests; all 11 payload checksums passed. Core module, VCS/dependency/component metadata and the skill matched the reviewed source. The post-publication report is a later documentation commit, not content added to the published tag/assets.

Adds the local read-only administrative console, managed Codex native-worker controls, strict invocation usage reports and compression policy corrections. Readonly Claude workers now expose only Read,Glob,Grep and deny native Agent/Task; broader research uses approved Core/MCP capabilities, with the write-worker contract unchanged. This is a delegation boundary rather than native TUI or account parity. The private legacy frontend .3 avoids runtime plugin SDK installation and requires an explicit reviewed update from older builds. Optional VERSION, RTK-OSS and Codebase readers remain narrow pilots; the diagnostic native evidence runner still refuses production.

PRs 41, 42, 43 and 44 each passed 15/15 checks. PR 48 passed 15/15 at its reviewed source (run). The released main then passed 16/16 jobs, and all five Release jobs passed, including the official five-case Claude protocol proof and exact Core version/help under private HOME/XDG on native ARM and amd64 Nehalem before archiving. A separate local downloaded-Core smoke passed AMD64 version/help; local ARM execution was not performed. No provider/model calls, local installation or production deployment occurred in that post-download check.

The new seven-case comparison retained 42 correct real attempts: input +2.85%, elapsed −1.44%; the 10%/5% targets failed. All 72 prior attempts remain preserved. Another 12 edit turns passed the declared oracles but missed the same targets: input −0.01257%, phase time −2.28091%, process time −2.46501%. Both arms used direct inspection, with no prefetch/Graft/Gateway. The 126 tally covers six backend-first cohorts only (18×4+42+12), not all repository attempts; PR30 prefetch/schema pilots and earlier MCP research remain separate. No grand total or heterogeneous causal saving is computed. The new edit harness is outside this release. PRs 45, 46, 47, 50 and 51 remain excluded. The global matrix is INCOMPLETE. These measurements predate the later changes and do not establish their economic effect. OpenCode removal, general adaptive execution, Claude equivalence, Antigravity and Context ingestion remain pending. See the tagged bilingual notes for scope, compatibility and rollback limits. Their pre-publication candidate language is preserved; the separate report above records actual publication.

The documentation follow-up audit passed the unchanged high-severity threshold with one residual low advisory in transitive deepmerge 4.3.1. Scoped review found a Node/SVGR build dependency, not a demonstrated Go HTTP/browser exploit path; no zero-vulnerability or universal-safety claim follows. Details and the retained low-threshold exit 1 are in the post-publication report above.

v0.9.2​

The v0.9.2 stable patch keeps the OpenCode-first architecture while restoring conformant federated Memory/Context results for Codex. It also exposes runtime model and reasoning choices through OpenCode's native picker, persists requested and effective selection metadata, classifies bridge failures without accepting partial output, drains federated initialization deterministically, unifies the documentation canvas, and adds complete English and Brazilian Portuguese locales. Complete notes live in release-notes/v0.9.2.md.

v0.9.0​

The v0.9.0 stable release makes the pinned OpenCode TUI the managed frontend for AUTO while IVOAI remains the session, executor, policy, quota, and knowledge control plane. Codex and Claude Code continue to own their subscription authentication; no provider credential is copied into OpenCode. It also adds resumable frontend ↔ executor session mappings, persistent multi-server scope/health visibility, an IVOAI theme and panel built with supported OpenCode plugin APIs, and an accessibility hardening pass for the self-hosted documentation portal. Complete notes live in release-notes/v0.9.0.md.

v0.8.0​

The v0.8.0 stable release adds all-enabled multi-server read federation, hardened Debian 12/LXC bootstrap, the embedded production documentation portal, and explicit remote Web MCP conformance. Its complete public notes live in release-notes/v0.8.0.md.

Stable releases are immutable tags built by GitHub Actions. Each release contains Linux amd64/arm64 binaries, the Memory/Context skill archive, and SHA-256 checksums.

The documentation portal exposes latest from the installed binary and preserves a versioned snapshot for each documented release. Release notes state migrations, fallback behavior, known limitations, and rollback instructions.
